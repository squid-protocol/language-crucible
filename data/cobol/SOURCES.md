# COBOL corpus sources

This folder was substantially expanded on 2026-08-28 to deepen CICS/mainframe
coverage for the GitGalaxy blAST engine's structural-signature benchmarks.
Every file below is real, unmodified source code pulled from a full clone of
the named upstream repository (held in the `gitgalaxy/data` full-repo pool),
never generated or rewritten. Where a repo's clone contained tool-generated
artifacts from prior GitGalaxy runs (forged JCL, `*_gitgalaxy_clean_*`
output directories), those were identified by header/marker inspection and
explicitly excluded — see notes below.

## Caveats

- **`aws-mainframe-modernization-carddemo`**: these files were not cloned
  directly from AWS's repo; they were found as an embedded fixture inside
  `che-che4z-lsp-for-cobol/tests/test_files/` (used upstream to test the
  COBOL Language Server). No `LICENSE` file ships with that embedded copy.
  AWS's CardDemo repo is publicly MIT-licensed, but that hasn't been
  independently verified against this exact copy's provenance — confirm
  against the upstream repo before any external redistribution.
- **`cics-banking-sample-application-cbsa`**: the clone's
  `src/base/cobol_src/*.jcl` files were found to carry
  `AUTOGENERATED BY GITGALAXY ZERO-TRUST FORGE` / `GITGJOB` headers,
  identifying them as synthetic output from a prior GitGalaxy run rather
  than real upstream JCL. They were excluded from both `cobol/` and `jcl/`.
  The `.cbl` programs in that same directory are genuine upstream IBM
  source (verified by header/copyright inspection) and were kept.
- Repos without a discoverable upstream `LICENSE` file were deliberately
  **not** added to this corpus in this pass (e.g. `Cobol-Projects`,
  `cobol-samples`, `COBOL_Tutorial`, `learning-cobol`) to keep this corpus's
  licensing well-documented, even though real code was available.
