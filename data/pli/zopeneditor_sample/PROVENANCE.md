# PL/I — IBM Z Open Editor sample

Source: https://github.com/IBM/zopeneditor-sample (Apache-2.0)
Files: `PLI/PSAM1.pli`, `PLI/PSAM1LIB.pli`, `PLI/PSAM2.pli`

Real IBM-published Enterprise PL/I: sequential file I/O, `%INCLUDE` members,
nested `PROCEDURE`s, `ON` units, and a `%PROCESS` compiler directive on line 1
(see gitgalaxy#3115 — the intent extractor picks that directive up).
